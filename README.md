## Дипломный проект. Задание 1: Юнит-тесты

### Автотесты для проверки программы, которая помогает заказать бургер в Stellar Burgers

### Реализованные сценарии

Протестированы API-ручки в следующих сценариях: 
* создание пользователя
* авторизация пользователя
* обновление информации о пользователе
* создание заказа
* получение информации о заказах конкреного пользователя

Процент покрытия 100% (отчет: `htmlcov/index.html`)

### Структура проекта

- `methods` - пакет, содержащий методы для работы с пользователем и с заказами
- `tests` - пакет, содержащий тесты, разделенные по классам (`test_create_order.py`, `test_create_user.py`, `test_login_user.py`, `test_update_user.py`, `test_get_orders_of_user.py`)

### Запуск автотестов

**Установка зависимостей**

> `$ pip install -r requirements.txt`

**Запуск автотестов и создание allure-отчета**

>  `$ pytest --alluredir=allure_results`
> 
>  `$ allure serve allure_results`
